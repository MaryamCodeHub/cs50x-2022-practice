# CS50x 2022 Practice

My solutions and learning progress for Harvard University's CS50x 2022 course, Introduction to Computer Science.

This repository documents my practice with C programming, algorithms, data structures, image processing, and file handling.

## Problem Sets

### 1. Hello

**Objective:** Write a basic C program that greets the user by name.

- **Input:** The user's name.
- **Expected output:** A greeting such as `Hello, Maryam`.
- **Concepts:** `printf`, `get_string`, variables, and basic program structure.

### 2. Mario Less

**Objective:** Recreate the half-pyramid pattern inspired by Super Mario.

- **Input:** The height of the pyramid.
- **Expected output:** Rows of hashes (`#`) arranged into a right-aligned pyramid.
- **Concepts:** Loops, nested loops, user input, and validation.

### 3. Cash

**Objective:** Calculate the minimum number of coins needed to return a given amount of change.

- **Input:** The amount of change owed.
- **Expected output:** The minimum number of coins required.
- **Concepts:** Greedy algorithms, arithmetic, functions, and input validation.

### 4. Caesar

**Objective:** Encrypt a message using Caesar's cipher by shifting letters by a given key.

- **Input:** A non-negative integer key and a plaintext message.
- **Expected output:** The corresponding ciphertext, with letter case and non-alphabetic characters preserved.
- **Concepts:** Command-line arguments, modular arithmetic, strings, and character manipulation.

### 5. Scrabble

**Objective:** Determine which of two players scores more points from their words using Scrabble letter values.

- **Input:** One word from each player.
- **Expected output:** The winner, or a tie if both words have equal scores.
- **Concepts:** Strings, arrays, loops, functions, and character scoring.

### 6. Plurality

**Objective:** Implement a plurality election in which the candidate with the most votes wins.

- **Input:** Candidate names and votes cast for candidates.
- **Expected output:** The candidate or candidates with the highest vote count.
- **Concepts:** Arrays, structures, functions, searching, and vote counting.

### 7. Runoff

**Objective:** Implement a ranked-choice election using voters' ranked preferences.

- **Input:** Candidate names and each voter's ranked choices.
- **Expected output:** The winner when a candidate receives a majority, or the appropriate result if the election ends in a tie.
- **Concepts:** Two-dimensional arrays, structures, vote tabulation, elimination, and repeated rounds.

### 8. Recover

**Objective:** Recover JPEG images from a memory card's raw data.

- **Input:** A raw memory-card image file.
- **Expected output:** Recovered JPEG image files saved separately.
- **Concepts:** File I/O, binary data, buffers, and JPEG signatures.

### 9. Filter Less

**Objective:** Apply image filters to bitmap images.

- **Input:** A bitmap image and a selected filter.
- **Expected output:** A modified image showing the selected effect, such as grayscale, sepia, reflection, or blur.
- **Concepts:** Pixel manipulation, RGB values, nested loops, arrays, and image processing.

### 10. Speller

**Objective:** Build a spell-checker that identifies misspelled words by comparing text against a dictionary.

- **Input:** A dictionary file and a text file to check.
- **Expected output:** Misspelled words, along with statistics such as words processed and elapsed time.
- **Concepts:** Hash tables, linked lists, pointers, dynamic memory allocation, file I/O, and algorithm efficiency.

## Technologies and Concepts

- **Language:** C
- **Core topics:** Algorithms, strings, arrays, functions, pointers, and memory management
- **Data structures:** Arrays, structures, hash tables, and linked lists
- **Additional topics:** File handling, command-line arguments, and image processing
